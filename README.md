# Liquid Glass Link-in-Bio (Android-First Edition)

A high-performance, zero-server Link-in-Bio web platform featuring a custom Liquid Glass aesthetic, dynamic aurora mesh gradients, on-device Recharts click analytics, QR code generation, and serverless contact forms.

## Quick Customization (`src/config.ts`)
You never need to touch the UI components to update your links. Open `src/config.ts` directly in the GitHub Mobile app or browser editor to customize:
- `profile`: Name, handle, avatar URL, tagline, bio, and live status badge.
- `socials`: Your Telegram, Threads, Instagram, GitHub, YouTube, X, and Discord links.
- `links`: Add, remove, or reorder cards and assign categories (`Featured`, `Wallpapers`, `Projects`, `Resources`).
- `embeds`: Toggle YouTube video, Spotify playlist, or Newsletter box.
- `contact`: Paste your free [Web3Forms](https://web3forms.com/) Access Key.
